## `[ 03 ]` &nbsp;PROJECT ARCHIVE

### 🌱 365Rise — Gamified Habit-Building Experience
> *365 days of rising, one habit at a time.*

**Status:** 💡 Concept / in planning. The features below are **planned, not yet implemented.**

Most habit trackers fail for a simple reason: consistency isn't a memory problem, it's a **motivation** problem. You tick a box, close the app, and nothing changes. No momentum, no reward, no reason to come back tomorrow.

365Rise is built around one idea: **make progress visible.** Every completed habit should feel like it's adding up to something.

| Planned feature | What it does |
|---|---|
| ⚡ XP and levels | Completing habits earns XP and raises your level |
| 🔥 Streak tracking | Watch your streak grow day after day |
| 🪙 Coins | Earned by completing *all* habits for the day |
| 🛒 Reward shop | XP boosts, streak shields, and themes |
| 🎮 Mini-games | Quick breaks so the routine never feels stale |
| 📅 Progress calendar | A full picture of how far you've come |

<br/>

### ✈️ SwiftVisa — AI Visa Eligibility Screening Agent
An AI-assisted application for screening visa eligibility.

- Interactive eligibility screening
- Retrieval-assisted answers using a FAISS vector index
- LLM-powered responses

`Python` · `Streamlit` · `FAISS` · `Groq API` · `Llama 3.1`

> ⚠️ Informational screening tool only. It is not legal or immigration advice.

<br/>

### 🧪 AI-Powered Drug Similarity Predictor
Explores molecular similarity through chemical representations and fingerprints.

- Processes supported SMILES strings or chemical formula inputs
- Generates molecular fingerprints with RDKit
- Calculates Tanimoto similarity
- Explores KNN-based prediction and visualization

`Python` · `RDKit` · `KNN` · `Matplotlib` · `Plotly`

> ⚠️ Computational similarity does **not** establish clinical equivalence or medical suitability.

<br/>

### 🖥️ OS Algorithm Animator
A web application for visualizing core operating-system algorithms.

| Category | Algorithms |
|---|---|
| CPU scheduling | FCFS, SJF, Round Robin, Priority |
| Disk scheduling | SSTF, SCAN, LOOK, C-SCAN |
| Page replacement | FIFO, LRU |

Interactive visualization with a Flask backend and MySQL integration.

`HTML` · `CSS` · `JavaScript` · `Python` · `Flask` · `MySQL`
